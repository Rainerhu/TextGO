# SnipDo vs TextGO 对比分析

## SnipDo 概述

SnipDo（前身 PantherBar）是一个 Windows 平台的文本选择快捷操作工具，通过 Microsoft Store 分发。
选中文本后弹出浮动工具栏，提供复制、搜索、翻译、分享等快捷操作。
免费版提供 80+ 内置动作，Pro 版（付费订阅）解锁无限扩展和自定义扩展创建。

## TextGO 的差距点（SnipDo 有而 TextGO 缺少的）

### 1. 扩展商店 / 扩展分享生态 ⭐ 重要
SnipDo 有内置扩展商店，用户可以一键安装社区贡献的扩展。扩展以 .pbar 格式打包分享。
TextGO 的脚本/提示词/搜索动作只能在本地创建，没有导入导出和社区分享机制。

**建议**：增加扩展导入/导出功能（JSON 格式），后续可考虑社区扩展仓库。

### 2. 剪贴板历史 ⭐ 中等
SnipDo 内置剪贴板历史功能，可以回溯之前复制的内容。
TextGO 没有剪贴板历史，只有操作执行历史。

**建议**：可作为可选功能添加，但不是核心差距（Windows 自带 Win+V 剪贴板历史）。

### 3. 第三方服务直接集成
SnipDo 有 Todoist、Trello、Notion、Skype、日历等直接集成扩展。
TextGO 没有预置的第三方服务集成。

**建议**：TextGO 可以通过脚本和搜索 URL 实现类似功能，但不如一键安装方便。
如果实现了扩展商店，社区可以贡献这些集成。

### 4. 工具栏布局多样性
SnipDo 支持水平、垂直、折叠水平三种工具栏布局，图标大小可调。
TextGO 目前只有水平布局。

**建议**：可考虑增加垂直布局选项，实现成本不高。

### 5. 按应用过滤扩展/规则
SnipDo 的每个扩展可以设置 noShowApps（排除应用）和 showOnlyApps（仅在指定应用显示）。
TextGO 只有全局黑名单，不支持按规则级别的应用过滤。

**建议**：在 Rule 类型中增加应用白名单/黑名单字段。

### 6. 拼写建议
SnipDo 内置拼写建议功能。
TextGO 没有。

**建议**：优先级低，可通过 AI 对话间接实现。

### 7. 内置翻译和货币转换
SnipDo 有开箱即用的翻译和货币转换扩展。
TextGO 需要用户自己配置 AI 提示词或脚本。

**建议**：可以预置一些常用的脚本/提示词模板，降低用户配置门槛。

## TextGO 的优势点（SnipDo 没有的）

1. **跨平台**：支持 macOS + Windows
2. **智能文本类型识别**：ML 模型 + 正则 + 自然语言检测 + 编程语言检测
3. **规则系统**：类型→动作的灵活映射，不同文本类型触发不同操作
4. **AI 对话集成**：7+ LLM 提供商，支持本地模型（Ollama/LM Studio）
5. **多种触发方式**：拖选/双击/Shift+点击/长按/键盘快捷键，各自独立配置
6. **静默模式**：直接执行不弹窗
7. **开源免费**：GPL-3.0，无付费墙
8. **隐私安全**：无遥测，本地处理，可审计

## 总结

TextGO 在核心功能（文本识别、规则系统、AI 集成、跨平台）上明显领先 SnipDo。
SnipDo 的优势主要在生态层面（扩展商店、第三方集成、社区分享）和一些便利性功能（剪贴板历史、拼写建议）。

最值得 TextGO 补齐的差距是**扩展导入导出和社区分享机制**，这是建立用户生态的关键。
其次是**工具栏布局多样性**和**按规则级别的应用过滤**，实现成本较低但能提升体验。
